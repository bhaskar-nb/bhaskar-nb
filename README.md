### What I build

I build practical **data analysis and business intelligence projects** that help teams understand performance, identify trends, and make better decisions without digging through raw spreadsheets.

My workflow is simple: **clean the data → analyze it → find the signal → build an interactive dashboard → communicate the insight.**

- **Business analysts** — trends, comparisons, KPIs, and exploratory analysis.
- **Decision-makers** — concise views of data that support faster decisions.
